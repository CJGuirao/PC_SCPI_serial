# Modern Lab assets

Generated with the built-in image_gen tool from the selected Modern Lab concept.
Original PNG alpha is preserved. The application scales the images at runtime.
The indicator line and button text are rendered by Tkinter, so they remain dynamic.

- concept.png: original selected concept sheet; design reference only.
- knob.png: front-facing rotary encoder, no baked-in index marker.
- button.png: blank molded pushbutton used for neutral function keys.
- Channel keys and live-refresh keys use native colored controls for clear states.

## Knob prompt
Use reference image only as style reference. Generate ONE production UI asset: the Modern Lab large rotary knob, black fine-ribbed rubber grip, charcoal subtly textured flat face and thin silver outer mounting ring, same style as supplied oscilloscope. Orthographic FRONT view, perfect circular symmetry, no perspective, no white index marker (the app will draw a movable marker), no text, no labels, no scale ticks, no other objects. Center knob exactly in square canvas, outer circle occupies 90% of width and height. Transparent background with genuine alpha. Soft restrained upper-left lighting and tiny contact shadow, clean isolated silhouette. Output a single square PNG asset, not a presentation board.

## Button prompt
Use this Modern Lab oscilloscope sheet as style reference. Create ONE isolated production UI asset: a blank rectangular light-gray physical oscilloscope pushbutton, front orthographic view. Slightly rounded corners, realistic shallow molded plastic face, silver gray beveled rim, soft thin shadow at bottom, clean industrial design. Button fills 94 percent of canvas width and 85 percent height. Landscape 2.5:1 aspect ratio. No text, no icons, no symbols, no background panel, no extra buttons. Genuine transparent background with alpha. This will be rendered at 100x40 pixels with live text overlaid.
